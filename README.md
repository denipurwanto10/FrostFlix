# FrostFlix

FrostFlix is a modern web application for tracking and discovering movies and TV shows. Built with React, Vite, and Tailwind CSS, it provides a sleek interface for managing your watchlist, searching for content, and tracking your viewing progress.

## Features

- **Movie & TV Show Search**: Find content across multiple sources
- **Watchlist Management**: Add/remove movies and shows to track your progress
- **Preferences**: Customize your viewing experience
- **Responsive Design**: Works on desktop and mobile devices

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- TypeScript
- TanStack React Query
- Radix UI components

## Getting Started

```bash
# Install dependencies
npm install

# Development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
